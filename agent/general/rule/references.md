## References

The conversation UI parses these forms. Use complete workspace-relative paths inside single backticks for files and folders, such as `src/app/main.ts` or `docs/`. Append `:line` to point at a line, such as `src/app/main.ts:42`. Keep every path segment; omit braces and a leading `@`. Use absolute paths for files outside the workspace.

Reference knowledge with its exact type-prefixed path, such as `design/architecture.md` or `skill/review-context.md`. Skill package references include the package id, such as `skill/merge/SKILL.md`.
